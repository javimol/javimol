# Javier Molina Vela

Computer vision and machine learning engineer. PhD in hand gesture recognition
from range (depth) data, Universidad Autónoma de Madrid (VPU-Lab), 2012.

## What I work on

- **Computer vision**: hand and human pose estimation, object tracking, face recognition
- **Machine learning**: synthetic training data, neural networks, genetic algorithms
- **Tooling**: human-in-the-loop annotation, Linux workstation tuning
